💨 吐音技巧 (Tonguing)

发音时嘴里轻念「Tu (吐)」，舌尖在齿龈轻轻一弹。切忌直接用肺部呼气，舌头是控制音符断连的关键！

🫁 呼吸与口型 (Breathing)

吹低音 G 和 A 时气息要平稳自然，像吹灭蜡烛一样温和；吹高音时稍加腹部支撑，不可用力过猛导致发尖。

✋ 手姿与按孔 (Posture)

用手指肚（柔软部分）按住音孔，而不是指尖。盖严音孔不可漏气，否则容易发出难听的杂音或漏气声。

⚖️ 右手支撑与平衡 (Balance)

吹奏高音 C 和 D 时左手松开了食指甚至背孔，笛子易晃动。右手大拇指在笛身下方轻托稳定笛身，嘴唇含稳吹口！

🎉 进阶挑战：解锁新音符 — 高音 C (1) 与 高音 D (2)

恭喜学生们熟练掌握了 B, A, G！现在让我们加入高音区两大关键音：高音 C (1 / Do) 与 高音 D (2 / Re)，组成完整的 G-A-B-C-D 五音音阶，向世界名曲进军！

🔍 高音 C (1) 指法要领

基础高音

8孔竖笛： 左手按住【背孔】与【第2孔】—— 特别提醒：第1孔（食指）必须放开！

6孔竹笛： 开 4, 5, 6 孔，按住上2孔并以适中平稳气流吹出高音 Do。

C 音 (高音 1)

  • B → C 转换： 抬起食指，按下中指。
  • A → C 转换： 抬起食指，保持中指按住。

🚀 高音 D (2) 指法要领

飞跃进阶

8孔竖笛： 左手【仅按第2孔】—— 大拇指背孔与第1孔完全放开！

6孔竹笛： 开 3, 4, 5, 6 孔（按住第1、2孔），中高音稍聚拢气流吹出高音 Re。

D 音 (高音 2)

  • C ↔ D 神奇机关： 中指保持按住第2孔，只需抬起/按下大拇指！
  • 口诀： “拇指一抬就是 D，拇指一按变成 C”。

💡 教学秘籍：高音持笛稳定诀窍

吹奏高音 D 时，由于左手拇指和食指全部放开，初学者极易握不稳笛子而倾斜。关键提示： 右手拇指在笛身下方提供稳定的向上支撑，嘴唇适度含稳吹口，做到“中指按准、拇指开关、笛身纹丝不动”。
